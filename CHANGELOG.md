## [0.1.0] - 2026-09-03

### Added

- Interactive Conventional Commit composer with preview, body, issue, and footer support.
- Repository and global TOML configuration for message policies and UI preferences.
- Staged-file review and exclusion before committing.
- Explicit signing control while preserving Git hooks, credentials, and output.
